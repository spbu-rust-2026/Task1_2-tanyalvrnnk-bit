# Задание 1_2 (Сумма с ограничителем)

Программа принимает последовательность целых положительных чисел, каждое из чисел находится на отдельной строке. Маркером конца последовательности будем считать `-1`. Необходимо вычислить сумму данного набора чисел, не учитывая значение маркера конца `-1`, и вывести ее в stdout. В случае, если перед маркером конца последовательности встретились данные, отличные от целых положительных чисел, следует вывести в stdout сообщение `NaN` и закончить работу.

## Примеры работы

1) Входные данные:
   ```
   1
   2
   3
   -1
   ```
   Выходные данные:
   ```
   6
   ```

2) Входные данные:
   ```
   1
   2
    three
   -1
   ```
   Выходные данные:
   ```
   NaN
   ```
